# Dilraj Kaur — Scientific Portfolio

A responsive, static personal portfolio built with HTML, CSS and JavaScript. Suitable for free GitHub Pages hosting.

## Preview locally
Open `index.html` in a browser, or run `python3 -m http.server 8000` in this folder and visit http://localhost:8000.

## Personalise before publishing
1. Replace `assets/profile-placeholder.svg` with your professional photo (e.g. `assets/profile.jpg`), then change the image path and alt text in `index.html`.
2. Add your actual PDF CV as `assets/Dilraj_Kaur_CV.pdf`. Until then, the CV buttons point to a missing file.
3. Verify research descriptions and check whether your CUH repository is public and appropriate to share.
4. Add confirmed LinkedIn URL and professional email to Contact.
5. Replace the publication topic placeholders with accurate bibliographic citations and DOI links.

## Publish with GitHub Pages
1. Create a public repository named `Dilraj-kaur.github.io` under your `Dilraj-kaur` GitHub account.
2. Upload the *contents* of this folder to the repository root (not the enclosing folder).
3. In repository Settings > Pages, choose **Deploy from a branch**, select `main` and `/(root)`, and Save.
4. Once deployed, visit https://dilraj-kaur.github.io/ . Publication may take a few minutes.

No build system or paid hosting is required. Google Fonts requires an internet connection; system fallbacks are included.
